Security headers

A quick reference for headers that help protect websites.

Content-Security-PolicyMitigates injection＋

Controls which sources a browser may load scripts, styles, images, and other resources from. Start with a restrictive policy and tune it to your application.

Strict-Transport-SecurityEnforces HTTPS＋

Instructs browsers to access the site only over HTTPS for a set period. Enable only after confirming HTTPS works across your domain.

X-Content-Type-OptionsPrevents MIME sniffing＋

Use nosniff to prevent browsers from interpreting a response as a different content type.

Referrer-PolicyLimits referrer data＋

Controls how much referrer information is sent with requests. strict-origin-when-cross-origin is a common starting point.

Permissions-PolicyRestricts browser features＋

Limits access to features such as camera, microphone, and geolocation. Disable any features your application does not need.

frame-ancestorsHelps prevent clickjacking＋

Set this directive in Content-Security-Policy to specify which sites can embed your pages in frames.

Headers are configured on your web server. This panel is a reference, not a live site scan.
